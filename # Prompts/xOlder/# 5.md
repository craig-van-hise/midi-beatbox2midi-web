**Context:** The UI Sensitivity slider needs to correctly scale the backend DSP threshold. The UI must behave so that `0` = 0 hits, and `5` = max hits. Because a higher backend threshold *reduces* hits, we must map the frontend values inversely before passing them to the WASM engine.

**Task:** Open `src/hooks/useHitManager.ts` and replace the `updateHits` function with this exact block:

```typescript
  const updateHits = useCallback(() => {
    const proc = processorRef.current;
    if (!proc || !audioBuffer) return;

    // --- FRONTEND SENSITIVITY SCALING ---
    // UI Slider range: 0.0 to 5.0
    // UI 5.0 -> We want max hits. The backend alpha must be 0.0 (lowest threshold wall).
    // UI 0.0 -> We want 0 hits. The backend alpha must be 50.0 (massive threshold wall).
    const uiSensitivity = paramsRef.current.sensitivity;
    const backendAlpha = (5.0 - uiSensitivity) * 10.0; 

    proc.setSensitivityMultiplier(backendAlpha);
    proc.setNoiseFloorOffset(paramsRef.current.noiseFloor);
    proc.setRefractoryPeriodMs(paramsRef.current.refractory);
    
    proc.calculateOnsets();
    const hits = proc.getTransients();
    setEngineHits(hits);
  }, [audioBuffer]); 
```
