
### **Master Engineering Prompt: State Reconciliation & UI Refinement**

**Task: Implement Persistent Hitpoint Logic, Functional Muting, and UI Compaction**

#### **1. Logic Tier: `useHitManager.ts` Refactor**
* **Unified State Management:** Create two memoized selectors from `engineHits` and `hitStates`:
    * **`renderableHits`:** The "Visual Truth." Contains all WASM hits, muted hits, and locked hits.
    * **`activeHits`:** The "Functional Truth." Filter out any hit with a `muted` state. This array must be used for Auditioning, MIDI Export, and the RTZ logic.
* **State Injection:** Ensure `locked` and `user-added` timestamps in `hitStates` are always present in both arrays, even if the sensitivity slider is at zero.
* **Selection State:** Add `selectedHitIndex` (number | null) to track the currently active triangle.

#### **2. Visual Tier: `SlicerCanvas.tsx` & `RulerCanvas.tsx`**
* **Precision Hit Targeting:** Modify the click handler so selection only triggers when clicking the **triangle head** (the top ~15-20px of the vertical line).
* **Hit States (Orange/Gray/Lock):**
    * **Selected:** Triangle turns **Orange** ($#FF8C00$).
    * **Muted:** Triangle turns **Gray** ($#808080$), and the **vertical line is removed**. It remains at the top of the waveform as a marker.
    * **Locked:** Overlay a small Lucide `Lock` icon on the triangle.
* **Loop Locators:** Style L/R locators in **Orange** with full-height "flagpole" lines and "L" / "R" text labels.

#### **3. Transport Tier: `useAudioPlayback.ts` & `Transport.tsx`**
* **Playhead Sync:** Refactor `requestAnimationFrame` logic to calculate playhead position using absolute `(AudioContext.currentTime - startTime) % duration`. Moving loop locators must **not** shift the playhead's relationship to the underlying audio.
* **RTZ Feature:** Add a **Return to Zero (RTZ)** button (Icon: vertical line + left triangle). Clicking it sets the playhead to the start of the file or the "L" locator.
* **Alignment:** Center the entire transport cluster at the bottom of the screen.

#### **4. Vertical Compaction (CSS/Tailwind)**
* **Title Bar:** Reduce height and padding by at least 40%.
* **Control Card:** Tighten vertical margins between sliders.
* **Overview Module:** Remove the "Overview" text label; eliminate top margins to reclaim space for the Main Workspace.
* **Goal:** Ensure the entire UI is visible without scrolling on a standard 1080p display.
