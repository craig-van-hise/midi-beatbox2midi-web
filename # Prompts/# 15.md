### **PHASE 2: The 3-Tier Mathematical Ruler**
**Objective:** Rewrite the RulerCanvas rendering to support Bar, Beat, and Grid subdivisions with high-contrast black/white styling.

1.  **`src/components/RulerCanvas.tsx` (Logic & Rendering):**
    * Update `RulerCanvasProps` to include `gridPulse: '8th' | '16th' | '32nd'`.
    * Delete the current grid drawing loop. Replace it with a strict 3-tier mathematical loop.
    * Use a pure white background (`ctx.fillStyle = '#ffffff'; ctx.fillRect(0,0,width,height);`) for maximum contrast.
    * Implement the 3-Tier math:
      ```typescript
      const beatsPerMeasure = timeSignature[0];
      const beatsPerSecond = tempo / 60;
      const samplesPerBeat = sampleRate / beatsPerSecond;
      const samplesPerMeasure = samplesPerBeat * beatsPerMeasure;
      
      const gridDivisionsPerBeat = gridPulse === '8th' ? 2 : gridPulse === '16th' ? 4 : 8;
      const samplesPerGrid = samplesPerBeat / gridDivisionsPerBeat;

      const startMeasure = Math.floor(startSample / samplesPerMeasure);
      const endMeasure = Math.ceil(endSample / samplesPerMeasure);

      ctx.fillStyle = '#000000'; // Black text
      ctx.font = 'bold 10px Inter';
      ctx.textAlign = 'left';

      for (let m = startMeasure; m <= endMeasure; m++) {
        const measureSample = m * samplesPerMeasure;
        
        // Loop through grid pulses within this measure
        for (let g = 0; g < beatsPerMeasure * gridDivisionsPerBeat; g++) {
          const tickSample = measureSample + (g * samplesPerGrid);
          const x = ((tickSample - startSample) / visibleSamples) * width;
          
          if (x >= 0 && x <= width) {
            ctx.beginPath();
            
            if (g === 0) {
              // TIER 1: Bar Line (Tallest, Thickest)
              ctx.strokeStyle = '#000000';
              ctx.lineWidth = 2;
              ctx.moveTo(x, height);
              ctx.lineTo(x, 0); // Full height
              ctx.fillText(`M${m + 1}`, x + 4, 10);
            } else if (g % gridDivisionsPerBeat === 0) {
              // TIER 2: Beat Line (Medium)
              ctx.strokeStyle = '#475569'; // slate-600
              ctx.lineWidth = 1.5;
              ctx.moveTo(x, height);
              ctx.lineTo(x, height - 14);
            } else {
              // TIER 3: Grid Pulse (Shortest, Thinnest)
              ctx.strokeStyle = '#94a3b8'; // slate-400
              ctx.lineWidth = 1;
              ctx.moveTo(x, height);
              ctx.lineTo(x, height - 6);
            }
            ctx.stroke();
          }
        }
      }
      ```
