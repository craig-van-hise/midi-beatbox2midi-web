**Task 2: Implement the Linear Multiplier in `src-cpp/Engine.cpp`**
Open `src-cpp/Engine.cpp` and locate the `calculateOnsets()` method. Find the `if (!medianBuffer.empty())` block (around line 98). Replace the entire block with this exact logic:

```cpp
        // Calculate Median using std::nth_element
        if (!medianBuffer.empty()) {
            size_t mid = medianBuffer.size() / 2;
            std::nth_element(medianBuffer.begin(), medianBuffer.begin() + mid, medianBuffer.end());
            float median = medianBuffer[mid];
            
            // 1. Calculate the base energy threshold
            // Because m_delta is > 0, this base threshold is never zero.
            float baseThreshold = median + m_delta;
            
            // 2. Pure Linear Multiplier
            // As UI sensitivity (m_alpha) decreases from 5.0 to 0.0, 
            // the multiplier increases linearly, raising the threshold.
            float clampedAlpha = std::max(0.0f, std::min(m_alpha, 5.0f));
            float linearMultiplier = 1.0f + ((5.0f - clampedAlpha) * 4.0f); // Scales from 1x to 21x
            
            // 3. Apply the multiplier
            m_thresholdEnvelope[m] = baseThreshold * linearMultiplier;
        }
```
